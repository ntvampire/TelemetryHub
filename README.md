> [!NOTE]
> **Текущий статус проекта:** Программный комплекс находится в активной эксплуатации. Поддерживается автономный сбор телеметрии 24/7 в качестве системной службы, автоматические обновления и диспетчеризация контроллеров **КСИТАЛ GSM**, **RADS CCU-825** и **ОВЕН ПЛК**.
> Диспетчерский интерфейс построен на базе **Avalonia UI** (графический движок Skia), что гарантирует максимальную отзывчивость, надежность и одинаково стабильную работу на **Windows 7 SP1 (32-бит и 64-бит)**, Windows 8, 8.1, 10, 11 и **Linux**.

Централизованный диспетчерский пункт телеметрии и мониторинга для контроллеров **КСИТАЛ GSM**, **RADS CCU-825** и **ОВЕН ПЛК**.

Система рассчитана на автономную круглосуточную работу (24/7), не требует предварительной установки .NET SDK на рабочем месте оператора и устойчива к аварийным отключениям электропитания.

## Установка на рабочем месте оператора

Развертывание программного комплекса осуществляется с помощью автономных установщиков Windows или архива Linux.

### 1. Выбор и загрузка дистрибутива
В разделе [Releases](https://github.com/ntvampire/TelemetryHub/releases) доступны 3 целевых пакета:
* **`telemetry-hub-win7-11-x64-setup-vX.X.X.exe`** — **64-битный установщик Windows**. Основной дистрибутив для рабочих станций диспетчеров с **Windows 7 SP1 x64**, 8, 8.1, 10 и 11 (x64).
* **`telemetry-hub-win7-x86-setup-vX.X.X.exe`** — **32-битный установщик Windows**. Специально для ПК с **Windows 7 SP1 x86 (32-бит)** и устаревших рабочих станций. Включает автоматическую проверку и установку системных библиотек Microsoft Visual C++ 2015–2022 Redistributable (x86).
* **`telemetry-hub-linux-x64-vX.X.X.tar.gz`** — **Пакет для Linux (x64)**. Портативный архив со скриптом запуска `run.sh` и фоновой службой сбора данных.

### 2. Запуск установки на Windows
* Запустите скачанный файл установщика (мастер установки запросит права администратора для первоначальной настройки системы).
* Выберите целевой каталог установки (по умолчанию `C:\Program Files\Telemetry Hub`, либо любой другой раздел: `D:\TelemetryHub`, `C:\TelemetryHub`).
* Программа установки автоматически:
  * Проверит наличие необходимых системных компонентов (включая Visual C++ Redistributable в 32-битном инсталляторе) и установит их при необходимости.
  * Развернет все исполняемые файлы в режиме **Self-Contained** (со встроенной средой выполнения .NET 8, установка внешних компонентов не требуется).
  * Настроит права доступа на каталог программы (`Users: Modify`), благодаря чему диспетчер сможет работать с базой данных `telemetry.db` без запросов UAC администратора.
  * Зарегистрирует и запустит системную службу Windows **`KsitalTelemetryWorker`** для круглосуточного фонового сбора данных по COM-порту (24/7).
  * Создаст ярлыки с фирменной иконкой на Рабочем столе и в меню «Пуск».
  * При последующих обновлениях программы база данных `telemetry.db` гарантированно сохраняется без перезаписи.
  * При чистой первичной установке база данных создается пустой и готовой к наполнению объектами оператора.

### 3. Первый запуск и настройка
* Запустите приложение с помощью ярлыка **«Telemetry Hub»** на Рабочем столе.
* При старте приложение автоматически открывает стартовый экран **«Журнал событий»**.
* Перейдите на вкладку **«Параметры»**:
  * В блоке **«Аппаратный GSM-модем»** выберите активный COM-порт модема и нажмите **«Применить порт»** (служба автоматически переключится на выбранный порт, активирует аппаратные линии RS-232 DTR/RTS, определит скорость порта, сотового оператора и уровень сигнала CSQ).
  * В блоке **«База данных и резервное копирование»** наполните систему объектами: вручную через кнопку «Добавить объект» на вкладке «Диспетчер объектов», либо загрузите базу в один клик через кнопку **«Импорт из GSMGuard (.txt)»** или файлы Excel/CSV (`.xlsx`, `.csv`).

## Ключевые возможности комплекса

* **Диспетчеризация объектов:**
  * Автоматическая группировка котельных и объектов по районам/участкам с адаптивными экспандерами.
  * Быстрый поиск и фильтрация по названию, номеру телефона или району.
  * Отображение сетевого питания 220V, напряжения аккумулятора, показаний температурных датчиков и времени последней связи.
  * Яркая индикация активных аварий прямо на заголовках групп и карточках объектов.

* **Интерактивное управление и команды оборудованию:**
  * Выделенное диалоговое окно **«Команды»** в строке каждого объекта (кнопка рядом с «Редактировать»).
  * Полный каталог специализированных SMS-команд под каждый тип контроллера:
    * **КСИТАЛ GSM:** постановка/снятие с контроля (`Ust/Otkl control`), запросы телеметрии (`Kak dela?`, `T?`, `Balans`, `U?`), управление реле и выходами (`Vkl/Otkl 1/2/3`).
    * **RADS CCU-825:** режимы охраны (`ARM`, `DISARM`, `PROTECT`), запросы статуса входов и выходов (`State`, `INS`, `OUTS`), управление выходами, перезагрузка и синхронизация времени.
    * **ОВЕН ПЛК / АСТ:** запросы состояния датчиков, сброс блокировок, пуск и остановка.
  * Автоматическая подстановка пароля прибора из карточки объекта с открытым отображением и расчётом SMS-текста всех команд.
  * Отправка команды в очередь в один клик с отображением статуса в уведомлении и фиксацией в Журнале событий.

* **Информационные индикаторы боковой панели (Footer):**
  * **Количество объектов:** строка вида `"Объектов: 228"` с реактивным пересчетом в реальном времени.
  * **Служба сбора данных:** статус работы с цветным маркером и возможностью перезапуска/запуска службы в один клик прямо по индикатору.
  * **Модем и COM-порт:** индикация связи с аппаратным GSM-шлюзом с выводом актуальной скорости (например, `COM1 (9600)`).
  * **Оператор связи SIM-карты:** определение сотовой сети модема (`MTS`, `MegaFon`, `Beeline`, `Tele2` и др.) при старте и восстановлении связи.
  * **Уровень сигнала GSM:** отображение процента и CSQ с цветовой дифференциацией качества связи (зеленый/желтый/красный), автозамером каждые 5 минут и внеочередным замером по клику.

* **Окно экстренной тревоги (AlarmWindow):**
  * Всплывает поверх всех окон (TopMost) при технологических авариях (пропадание 220V, выход температур за уставки, сработка охранно-пожарных шлейфов).
  * Специализированный 3-тональный звуковой сигнал тревоги (PCM WAV).
  * Кнопки «Подтвердить» и «Отложить на 5 минут» (с автоматическим повторным оповещением, если авария не устранена).

* **Журнал событий с авторотацией:**
  * Стартовый экран по умолчанию: фиксация аварий, штатных отчетов телеметрии, отправленных команд оператора и служебных SMS.
  * Автоматическая ротация до 100 последних записей для максимальной производительности.
  * Подтверждение тревог оператором («Подтвердить» на карточке и «Подтвердить все» в шапке).

* **Фильтрация спама и очистка памяти SIM-карты:**
  * Сообщения от операторов связи (баланс, реклама, МЧС) не создают фантомных объектов и сохраняются в Журнал как «Служебные».
  * Модем гарантированно очищает память SIM-карты (`AT+CMGD`) в блоке `finally` после вычитки каждого SMS.

* **Резервное копирование и миграция данных:**
  * Автоматический ежедневный бэкап рабочей базы данных (хранение до 10 последних копий).
  * Мгновенный импорт из резервных копий **GSMGuard (.txt)** с автораспознаванием типов приборов (КСИТАЛ, CCU825, ОВЕН), районов и паролей.
  * Экспорт и импорт списка объектов в Excel (`.xlsx`) и CSV.

* **Встроенное обновление ПО:**
  * Проверка релизов и установка обновлений с GitHub в один клик прямо из раздела «Параметры» (с автоматическим определением архитектуры x86/x64).

## Архитектура решения

* **Core** — доменные модели (`MonitoredObject`, `AlarmEvent`), генератор SMS-команд (`DeviceCommandBuilder`), нормализатор телефонов E.164, парсер резервных копий GSMGuard (CP1251) и сервис экспорта Excel/CSV.
* **Modem.Engine** — прямое взаимодействие с GSM-модемом по COM-порту (поддержка RS-232 линий DTR/RTS, автоопределение скорости порта 9600-115200, AT-команды, декодирование PDU UCS-2/7-bit, опрос оператора `AT+COPS?` и уровня сигнала `AT+CSQ`).
* **Parser.*** — специализированные парсеры телеметрии для контроллеров КСИТАЛ GSM, RADS CCU-825 и ОВЕН ПЛК.
* **Storage.Sqlite** — база данных SQLite в отказоустойчивом режиме WAL с таймаутом против блокировок, таблицей `SystemStatus` для безопасного межпроцессного взаимодействия (IPC) и ротацией журнала.
* **Service.Worker** — системная служба (Windows Service / Linux Daemon) для автономного круглосуточного сбора данных и управления модемом 24/7.
* **UI.Avalonia** — универсальный диспетчерский интерфейс (Avalonia UI / Skia) для Windows 7 SP1 (x86/x64), 8, 10, 11 и Linux.
