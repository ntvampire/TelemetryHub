# Telemetry Hub v2.0.0

Централизованный диспетчерский пункт телеметрии и мониторинга для контроллеров **КСИТАЛ GSM**, **RADS CCU-825** и **ОВЕН ПЛК**.

Система рассчитана на автономную круглосуточную работу (24/7), не требует предварительной установки .NET SDK на рабочем месте оператора и устойчива к аварийным отключениям электропитания.

---

## Установка на рабочем месте оператора

Развертывание программного комплекса осуществляется с помощью единого автономного установщика Windows.

### 1. Загрузка установщика
* Перейдите в раздел [Releases](https://github.com/ntvampire/TelemetryHub/releases) и скачайте актуальный установочный файл:  
  **`telemetry-hub-setup-v2.0.1.exe`**

### 2. Запуск установки
* Запустите скачанный файл `telemetry-hub-setup-v2.0.1.exe` (мастер установки запросит права администратора для первоначальной настройки системы).
* Выберите целевой каталог установки (по умолчанию `C:\Program Files\Telemetry Hub`, либо любой другой раздел: `D:\TelemetryHub`, `C:\TelemetryHub`).
* Программа установки автоматически:
  * Развернет все исполняемые файлы в режиме **Self-Contained** (со встроенной средой выполнения .NET 8).
  * Настроит права доступа на каталог программы (`Users: Modify`), благодаря чему диспетчер сможет работать с базой данных `telemetry.db` без запросов UAC администратора.
  * Зарегистрирует и запустит системную службу Windows **`KsitalTelemetryWorker`** для круглосуточного фонового сбора данных по COM-порту (24/7).
  * Создаст ярлыки с фирменной иконкой на Рабочем столе и в меню «Пуск».
  * При последующих обновлениях программы база данных `telemetry.db` гарантированно сохраняется без перезаписи.
  * При чистой первичной установке база данных создается пустой и готовой к наполнению объектами оператора.

### 3. Первый запуск и настройка
* Запустите приложение с помощью ярлыка **«Telemetry Hub»** на Рабочем столе.
* При старте приложение автоматически открывает стартовый экран **«Журнал событий»**.
* Перейдите на вкладку **«Параметры»**:
  * В блоке **«Аппаратный GSM-модем»** выберите активный COM-порт модема и нажмите **«Применить порт»** (служба автоматически переключится на выбранный порт и отобразит уровень сигнала CSQ).
  * В блоке **«База данных и резервное копирование»** можно наполнить систему объектами: добавить котельные вручную на вкладке «Объекты» либо загрузить через кнопку **«Импорт из GSMGuard (.txt)»** или файлы Excel/CSV (`.xlsx`, `.csv`).

## Ключевые возможности комплекса

* **Диспетчеризация объектов:** автоматическая группировка котельных по районам и участкам с индикацией активных аварий и раскрывающимися группами (аккордеонами).
* **Окно экстренной тревоги (AlarmWindow):**
  * Всплывает поверх всех окон (TopMost) при авариях (пропадание 220V, сработка охранно-пожарных шлейфов, выход температур за границы).
  * Громкий специализированный 3-тональный звуковой сигнал тревоги (PCM WAV).
  * Кнопки «Подтвердить» и «Отложить на 5 минут» (с автоматическим повторным оповещением).
* **Журнал событий с ротацией:** фиксация аварий, штатной телеметрии, исходящих команд диспетчера и служебных SMS оператора с автоматической ротацией до 100 записей.
* **Фильтрация спама и служебных SMS:** сообщения от неизвестных номеров и операторов связи не засоряют список котельных и безопасно сохраняются в Журнале со статусом «Служебное».
* **Гарантированная очистка SIM-карты:** аппаратный модем автоматически удаляет обработанные SMS из памяти SIM-карты (`AT+CMGD`), предотвращая зависания.
* **Автоматическое резервное копирование:** ежедневное создание копий рабочей базы данных с авторотацией (хранение до 10 последних копий).
* **Встроенное обновление с GitHub:** проверка релизов и установка обновлений в один клик прямо из окна «Параметры».

## Архитектура решения

* **Core** — доменные модели объектов и аварий, генератор SMS-команд, нормализатор телефонов E.164, парсер резервных копий GSMGuard (CP1251).
* **Modem.Engine** — прямое взаимодействие с GSM-модемом по COM-порту (AT-команды, кодирование и декодирование PDU UCS-2/7-bit).
* **Parser.*** — специализированные парсеры телеметрии для контроллеров КСИТАЛ GSM, RADS CCU-825 и ОВЕН ПЛК.
* **Storage.Sqlite** — база данных SQLite в отказоустойчивом режиме WAL с таймаутом 5 секунд против блокировок и таблицей `SystemStatus` для бесконфликтного IPC.
* **Service.Worker** — системная служба Windows для автономного круглосуточного сбора данных и управления модемом 24/7.
* **UI.WinUI** — пользовательский интерфейс оператора на WinUI 3 (Windows App SDK / Fluent Design) с поддержкой светлой и темной тем оформления.
