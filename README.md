# Telemetry Hub

Централизованный диспетчерский пункт телеметрии и мониторинга для контроллеров **КСИТАЛ GSM**, **RADS CCU-825** и **ОВЕН ПЛК**.

Система рассчитана на автономную круглосуточную работу (24/7) и устойчива к аварийным отключениям электропитания.

## Установка на целевом ПК

Приложение скомпилировано в автономном режиме (**Self-Contained**) и не требует предварительной установки .NET SDK или сторонних библиотек.

### 1. Скачивание и распаковка
* Перейдите в раздел [Releases](https://github.com/ntvampire/ksital-telemetry-hub/releases) и скачайте архив последней версии (`telemetry-hub-vх.х.х.zip` или инсталлятор `telemetry-hub-setup-vх.х.х.exe`).
* Распакуйте содержимое архива в постоянный рабочий каталог на диске (рекомендуется `C:\TelemetryHub`).

### 2. Первоначальная настройка службы
* Откройте рабочую папку.
* Кликните правой кнопкой мыши по файлу **`install.bat`** и выберите **«Запуск от имени администратора»**.
* Скрипт автоматически:
  * Зарегистрирует и запустит службу Windows `KsitalTelemetryWorker` со статусом автозапуска (24/7).
  * Настроит автоматический перезапуск службы при сбоях.
  * Создаст ярлык **«Telemetry Hub»** на Рабочем столе.

### 3. Первый запуск рабочего места
* Запустите приложение с помощью ярлыка на Рабочем столе (или через `run_winui.bat` / `run_winui.ps1` / `KsitalTelemetryHub.UI.WinUI.exe`).
* При первом старте система автоматически инициализирует базу данных SQLite в отказоустойчивом режиме **WAL** (файл `telemetry.db` в каталоге программы).
* Стартовым экраном по умолчанию открывается **«Журнал событий»**.
* Для настройки оборудования откройте раздел **«Параметры»**, выберите COM-порт модема и нажмите **«Применить порт»**.

## Обновление программы

В диспетчерский интерфейс встроен механизм обновления:
1. В главном окне откройте **«Параметры»** и нажмите **«Проверить обновления»**.
2. При наличии новой версии программа покажет список изменений и предложит установить релиз.
3. Система автоматически обновит комплекс с сохранением рабочей базы данных.

## Архитектура решения

* **Core** — общие структуры данных, отчеты телеметрии и конструктор команд.
* **Modem.Engine** — взаимодействие с GSM-модемом по AT-командам и декодирование PDU.
* **Parser.*** — модули разбора сообщений КСИТАЛ, RADS CCU-825 и ОВЕН ПЛК.
* **Storage.Sqlite** — хранилище объектов, телеметрии, журнала событий и очереди команд (WAL-режим, таймаут 5 сек, ротация журнала до 100 записей).
* **Service.Worker** — системная служба Windows для круглосуточного приема SMS, отправки команд и фиксации событий.
* **UI.WinUI** — современный диспетчерский интерфейс (WinUI 3 / Windows App SDK) со сгруппированными карточками объектов, Журналом событий, управлением устройствами, резервным копированием и автообновлением.
