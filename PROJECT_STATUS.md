# Telemetry Hub — ТЗ и статус проекта

## 1. Общее описание
Программный комплекс **Telemetry Hub** для круглосуточного (24/7) мониторинга и диспетчеризации контроллеров **КСИТАЛ GSM**, **RADS CCU-825** и **ОВЕН ПЛК**.
Система разработана для автономной работы и устойчива к внезапным отключениям электроэнергии (автоматическое восстановление, предотвращение коррупции файлов базы данных).

> **Статус релиза:** Полнофункциональный кроссплатформенный комплекс на базе единого производительного графического движка **Avalonia UI** (Skia) со 100% поддержкой Windows 7 SP1 (x86/x64), 8, 8.1, 10, 11 и Linux.

## 2. Архитектура проекта
* **Core**: Доменные модели (`MonitoredObject`, `AlarmEvent`), нормализация телефонов E.164 (`PhoneNumber`), генератор SMS-команд, реестр парсеров (`TelemetryParserRegistry`), а также `ImportExportService` для работы с Excel и CSV.
* **Modem.Engine**: Модуль связи с GSM-модемом по COM-порту (AT-команды, RS-232 сигналы DTR/RTS, автободрейт 9600-115200, декодирование PDU UCS-2/7-bit).
* **Parser.***: Специфичные модули разбора сообщений для контроллеров КСИТАЛ, RADS CCU-825 и ОВЕН ПЛК.
* **Storage.Sqlite**: База данных SQLite. Включен режим **WAL** и `DefaultTimeout=5` для защиты данных и предотвращения блокировок при конкурентном доступе между UI и фоновой службой. Таблица `SystemStatus` для бесконфликтного IPC. Автоматическая ротация журнала событий до 100 записей (`RotateJournalEventsAsync`).
* **Service.Worker**: Системная служба Windows (Windows Service) / Linux-демон для фонового сбора данных 24/7 без необходимости активного сеанса пользователя. Монопольно владеет COM-портом.
* **UI.Avalonia**: Единый диспетчерский интерфейс на **Avalonia UI** (Skia, светлая/темная тема, группировка по районам, Журнал событий, модальное управление объектами и командами, импорт/экспорт, автобэкап и проверка обновлений с GitHub).
* **Tools.Simulator**: Утилита генерации тестовых событий и тревог для отладки UI без модема.

## 3. Развертывание и обновления
* **Сборка**: Self-contained пакеты со встроенной средой .NET 8. Установщики компилируются через **Inno Setup** (сохранение `telemetry.db` при накате обновлений, автоматическая регистрация службы, создание ярлыков, права `Users: Modify`).
* **Сетка релизов (3 файла):**
  1. `telemetry-hub-win7-11-x64-setup-vX.X.X.exe` (Windows 7–11 x64)
  2. `telemetry-hub-win7-x86-setup-vX.X.X.exe` (Windows 7–11 x86 со встроенным VC++ Redistributable)
  3. `telemetry-hub-linux-x64-vX.X.X.tar.gz` (Linux x64)
* **CI/CD**: Настроен GitHub Actions (`release.yml`). Сборка запускается автоматически при пуше тега версии.
* **Автоматизация**: Скрипты `release_patch.bat` и `release_minor.bat` (вызывают `bump_release.ps1`), которые запрашивают Release Notes, повышают версию и пушат тег на сервер.
* **CLI Runner**: `run_ui.bat` / `run_ui.ps1` для быстрого запуска рабочего места оператора в среде Windows.

## 4. Текущий статус
* [x] Разработка базовой архитектуры, модулей декодирования PDU и парсеров контроллеров.
* [x] Настройка службы сбора данных `Service.Worker` (Windows Service).
* [x] Отказоустойчивость: детерминированная инициализация SQLite в WAL-режиме с `PRAGMA synchronous = NORMAL`.
* [x] Межпроцессное взаимодействие без аппаратных коллизий: таблица `SystemStatus` для передачи статуса модема и CSQ в UI.
* [x] Создание интерфейса на Avalonia UI (Skia) с адаптивными экспандерами, быстрыми командами и индикацией качества связи.
* [x] Управление объектами (добавление, редактирование, быстрые команды) через модальные окна.
* [x] Импорт и экспорт базы объектов (XLSX, CSV от GSM Guard) с автонормализацией типов и телефонов.
* [x] Автоматизация сборок: Inno Setup и CI/CD (GitHub Actions).
* [x] Журнал событий: стартовый экран, авторотация до 100 записей, подтверждение тревог.
* [x] Всплывающее окно тревоги (`AlarmWindow TopMost`) со звуковой сигнализацией и откладыванием на 5 минут.
* [x] Поддержка RS-232 модемов (Teleofis RX100-R2: сигналы DTR/RTS, автоопределение бодрейта).
* [x] 32-битный установщик под Windows 7 SP1 x86 с комплектом VC++ Redistributable.
* [x] **Унификация UI**: вывод WinUI 3 из эксплуатации, переход на единую кодовую базу Avalonia UI и стандартизированный состав релизов из 3 файлов.
