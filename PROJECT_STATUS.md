# Telemetry Hub — ТЗ и статус проекта

## 1. Общее описание
Программный комплекс **Telemetry Hub** для круглосуточного (24/7) мониторинга и диспетчеризации контроллеров **КСИТАЛ GSM**, **RADS CCU-825** и **ОВЕН ПЛК**.
Система разработана для автономной работы и устойчива к внезапным отключениям электроэнергии (автоматическое восстановление, предотвращение коррупции файлов базы данных).

## 2. Архитектура проекта
* **Core**: Доменные модели (`MonitoredObject`, `AlarmEvent`), нормализация телефонов E.164 (`PhoneNumber`), генератор SMS-команд, реестр парсеров (`TelemetryParserRegistry`), а также `ImportExportService` для работы с Excel и CSV.
* **Modem.Engine**: Модуль связи с GSM-модемом по COM-порту (AT-команды, декодирование PDU UCS-2/7-bit).
* **Parser.***: Специфичные модули разбора сообщений для контроллеров КСИТАЛ, RADS CCU-825 и ОВЕН ПЛК.
* **Storage.Sqlite**: База данных SQLite. Включен режим **WAL** и `DefaultTimeout=5` для защиты данных и предотвращения блокировок при конкурентном доступе между UI и фоновой службой. Таблица `SystemStatus` для бесконфликтного IPC.
* **Service.Worker**: Системная служба Windows (Windows Service) для фонового сбора данных 24/7 без необходимости активного сеанса пользователя. Монопольно владеет COM-портом.
* **UI.WinUI**: Основной диспетчерский интерфейс на **WinUI 3 / Windows App SDK** (Fluent Design, светлая/темная тема, сгруппированные карточки, журнал тревог, управление объектами, импорт/экспорт).
* **UI.Desktop**: Классический интерфейс диспетчера на WPF (.NET 8).
* **Tools.Simulator**: Утилита генерации тестовых событий и тревог для отладки UI без модема.

## 3. Развертывание и обновления
* **Сборка**: Self-contained пакет под `win-x64`. Установщик генерируется через **Inno Setup** (с сохранением `telemetry.db` при накате обновлений, автоматической регистрацией службы и созданием ярлыков).
* **CI/CD**: Настроен GitHub Actions (`release.yml`). Сборка запускается автоматически при пуше тега версии. Готовый `telemetry-hub-setup-*.exe` публикуется в релизах GitHub.
* **Автоматизация**: Локальные скрипты `release_patch.bat` и `release_minor.bat` (вызывают `bump_release.ps1`), которые запрашивают Release Notes, автоматически повышают версию проекта в `.csproj` и пушат тег на сервер.
* **CLI Runner**: `run_winui.ps1` для быстрой сборки и запуска рабочего места в среде Windows PowerShell.
