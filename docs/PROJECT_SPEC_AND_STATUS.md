# Telemetry Hub — Паспорт проекта, ТЗ и история разработки

Данный документ фиксирует полную информацию о программном комплексе **Telemetry Hub**: архитектуру, техническое задание, историю изменений по версиям, текущий статус и план дальнейших работ. Предназначен для бесшовного продолжения разработки в новых рабочих сессиях.

---

## 1. Общие сведения о проекте

* **Название проекта:** Telemetry Hub (КСИТАЛ Телеметрия Хаб).
* **Назначение:** Централизованный диспетчерский пункт мониторинга, оповещения и интерактивного управления для распределенных технологических объектов и котельных, оборудованных GSM-контроллерами.
* **Поддерживаемое оборудование:**
  1. **КСИТАЛ GSM** (Кситал GSM-4Т, GSM-8Т, GSM-12Т и др.).
  2. **RADS CCU-825** (CCU-825-HOME, CCU-825-SMART, CCU-422).
  3. **ОВЕН ПЛК** (ПЛК / АСТ телеметрия).
* **Режим эксплуатации:** 24/7 (непрерывная круглосуточная работа), без утечек оперативной памяти, с автовосстановлением после сбоев и отключений питания.
* **Репозиторий:** `https://github.com/ntvampire/TelemetryHub.git` (ветка `main`).
* **Актуальный релиз:** **`v2.2.0`** (Опубликован в GitHub Releases).

---

## 2. Поддерживаемые платформы и архитектура интерфейса

Диспетчерский интерфейс программного комплекса полностью унифицирован на базе **Avalonia UI** (графический движок Skia).

**Преимущества архитектуры интерфейса:**
- Прямой высокопроизводительный рендеринг через Skia без задержек WinRT/C++ маршалинга и DirectX XAML Islands.
- Полная самодостаточность (`Self-Contained` .NET 8): отсутствие зависимостей от Windows App SDK.
- 100% совместимость со всеми операционными системами: **Windows 7 SP1 (32-бит и 64-бит)**, Windows 8, 8.1, 10, 11 и **Linux**.

**Сетка дистрибутивов релиза (3 целевых файла):**
1. **`telemetry-hub-win7-11-x64-setup-vX.X.X.exe`** — 64-битный инсталлятор для Windows 7 SP1 x64, 8, 8.1, 10 и 11.
2. **`telemetry-hub-win7-x86-setup-vX.X.X.exe`** — 32-битный инсталлятор для Windows 7 SP1 x86 с комплектом библиотек Microsoft Visual C++ 2015–2022 Redistributable (x86).
3. **`telemetry-hub-linux-x64-vX.X.X.tar.gz`** — архив со скриптом запуска `run.sh` и фоновой службой для серверов и АРМ на Linux.

## 3. Архитектура решения

Решение `KsitalTelemetryHub.sln` разделено на слабосвязанные модули:

```
src/
├── Core/                   # Доменные модели, валидация номеров, генератор SMS-команд, импорт/экспорт
├── Modem.Engine/           # Низкоуровневый драйвер GSM-модема (COM-порт, RS-232 сигналы DTR/RTS, автоопределение бодрейта, AT-команды, PDU, CSQ)
├── Parser.Ksital/          # Парсер входящих SMS контроллеров КСИТАЛ GSM
├── Parser.Ccu825/          # Парсер входящих SMS контроллеров RADS CCU-825
├── Parser.Owen/            # Парсер входящих SMS контроллеров ОВЕН ПЛК
├── Storage.Sqlite/         # EF Core + SQLite (WAL mode, busy_timeout=5000, IPC-таблица SystemStatus)
├── Service.Worker/         # Системная служба 24/7 (Windows Service / автономный фоновый процесс)
├── UI.Avalonia/            # Универсальный диспетчерский интерфейс Avalonia UI для Windows (x86/x64) и Linux
└── Tools.Simulator/        # Симулятор GSM-модема и контроллеров для тестов без «железа»
tests/
├── Modem.Engine.Tests/     # 18 тестов
├── Parser.Ksital.Tests/    # 14 тестов
├── Parser.Ccu825.Tests/    # 12 тестов
└── Parser.Owen.Tests/      # 2 теста
```

## 4. Реализованный функционал

### 4.1. Двухзвенная архитектура (Worker + UI)
* **`Service.Worker`:** Фоновая служба для непрерывного сбора данных 24/7. Автономно опрашивает модем, парсит входящие SMS, пишет телеметрию в базу данных SQLite, отправляет исходящие команды из очереди. Управляется системным диспетчером служб Windows (`sc.exe create/start/stop/delete`) или работает как кроссплатформенный демон (`dotnet Service.Worker.dll`).
* **`UI.Avalonia`:** Графический интерфейс диспетчера. Не занимает COM-порт модема, общается со службой через базу данных `telemetry.db` и таблицу межпроцессного взаимодействия `SystemStatus`.

### 4.2. Низкоуровневый модемный движок (Modem.Engine)
* Прямое управление COM-портом (RS-232 / USB Virtual COM).
* **Аппаратные сигналы RS-232:** Принудительное удержание `DtrEnable = true` и `RtsEnable = true`. Обеспечивает пробуждение и питание аппаратных преобразователей уровня (MAX232) во внешних модемах типа **TELEOFIS RX100-R2**, а также корректную работу аппаратного контроля потока (`&K3`).
* **Мульти-рейт автоопределение скорости:** Интеллектуальное сканирование скоростей COM-порта (9600 -> 115200 -> 19200 -> 57600 -> 38400) с двойным пробуждающим импульсом `AT\r`. Позволяет автоматически цеплять как классические телеметрические модемы (9600 бод), так и современные USB-модемы (115200 бод) без ручной перенастройки конфигов.
* Формат команд: Строгое соответствие Hayes AT-стандарту (завершающий байт `\r` 0x0D без лишнего LF), подавление эхо `ATE0`, автоочистка буфера от мусора.
* Декодирование PDU: Поддержка 7-битного GSM алфавита и 16-битного UCS-2 (русский текст).
* Отправка SMS: Гарантированная передача текстовых команд с ожиданием подтверждения `+CMGS`.
* Замер качества сотовой связи: Периодический опрос уровня сигнала (`AT+CSQ`) и имени сотового оператора (`AT+COPS?`).

### 4.3. Поддержка GSM-контроллеров
1. **КСИТАЛ GSM:**
   - Чтение температуры датчиков (T1..T6 / T1..T8), реле (R1..R4), входов контроля (S1..S8), напряжения питания 220V/аккумулятора.
   - Фильтрация служебных SMS (`Vopros`, `Kak dela?`, ответы на команды).
2. **RADS CCU-825:**
   - Чтение аналоговых и дискретных входов, температуры, баланса, питания.
3. **ОВЕН ПЛК:**
   - Чтение текстовых статусных телеграмм и аварийных сигналов.

### 4.4. Тревоги, аварии и оповещения
* Автоматическая фиксация аварий: пропадание 220V, падение температуры ниже порога, срабатывание охранно-пожарных датчиков.
* Немодальное окно тревоги (`AlarmWindow`) поверх всех окон с воспроизведением 3-тональной сирены (`SoundService`).
* Квитирование тревог диспетчером с фиксацией времени и имени оператора.

### 4.5. Статусная панель (Сайдбар)
1. **Служба сбора:** цветовой бейдж активности фонового Worker'а (по таймштампу `HeartbeatUtc`).
2. **База данных:** индикация подключения к SQLite.
3. **Модем и порт:** аппаратный статус GSM-шлюза с выводом актуальной скорости (например, `COM1 (9600)`).
4. **Оператор связи SIM:** отображение сети (`MTS`, `MegaFon`, `Beeline` и др.).
5. **Сигнал сотовой сети:** шкала CSQ и процент (с цветовой индикацией качества), автоматический опрос раз в 5 минут и внеочередной замер по клику.

### 4.6. База данных, бэкапы и миграция данных
* База данных: `telemetry.db` размещается строго в каталоге приложения.
* Права доступа: инсталлятор назначает встроенной группе `Users` права `Modify` на папку `{app}`, исключая блокировки UAC при работе оператора без прав администратора.
* **Резервное копирование:**
  - Создание безопасного снапшота базы через команду `VACUUM INTO` (безопасно для WAL-режима).
  - Автоматическая ротация: сохраняется не более 10 последних копий (`telemetry_backup_*.db`).
  - Ежедневный автоматический фоновый бэкап при запуске программы.
  - Ручное создание резервной копии и восстановление из файла.
* **Импорт из GSMGuard:** Прямой импорт резервных копий GSMGuard (`.txt`, кодировка CP1251) с автораспознаванием типов приборов (КСИТАЛ, CCU-825, ОВЕН), номеров, названий, паролей и районов.
* **Excel / CSV:** Экспорт всей базы объектов в `.xlsx` и импорт из таблиц Excel / CSV.

### 4.7. Анти-спам и память SIM-карты
* Сервисные SMS от сотовых операторов (реклама, баланс, уведомления МЧС) не создают фантомных объектов и классифицируются как «Служебные».
* Модем гарантированно удаляет прочитанные SMS из памяти SIM-карты (`AT+CMGD`) в блоке `finally`.

## 6. Процесс сборки и публикации релизов (CI/CD)

1. **Локальная сборка установщиков:**
   - Скрипт: `build_release.ps1 -Version "X.X.X"`
   - Проверяет и при необходимости автоматически подтягивает `vc_redist.x86.exe` (из `D:\Projects\Redist` или CDN Microsoft).
   - Собирает Avalonia UI & Worker (win-x64, win-x86, linux-x64) и компилирует:
     - `installer-avalonia-x64.iss` -> `dist/telemetry-hub-win7-11-x64-setup-vX.X.X.exe` (64-бит для Windows 7–11)
     - `installer-avalonia-x86.iss` -> `dist/telemetry-hub-win7-x86-setup-vX.X.X.exe` (32-бит для Windows 7–11 с VC++ Redistributable)
     - tar.gz -> `dist/telemetry-hub-linux-x64-vX.X.X.tar.gz`

2. **Автоматическая публикация на GitHub:**
   - Настроен рабочий процесс `.github/workflows/release.yml`.
   - Триггер: отправка тега вида `v*.*.*` в репозиторий (`git push origin vX.X.X`).
   - GitHub Actions автоматически компилирует все 3 версии, формирует релиз и прикрепляет к нему 3 готовых дистрибутива.
