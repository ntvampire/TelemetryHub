\# Техническое задание: Диспетчерский комплекс телеметрии (WinUI 3 / .NET 8)



\---



\## 1. Введение и назначение системы

Комплекс предназначен для круглосуточного (24/7) автономного мониторинга, диспетчеризации и управления распределенной сетью объектовых GSM-контроллеров:

\* \*\*КСИТАЛ GSM\*\* (модели 4T, 8T, 12T и модификации)

\* \*\*RADS CCU\*\* (CCU-825, CCU-422)

\* \*\*ОВЕН ПЛК\*\* (контроллеры с GSM/SMS-информированием)



Система проектируется с расчетом на работу в режиме необслуживаемого сервера/диспетчерского поста в условиях нестабильного электроснабжения и рисков аварийного отключения питания.



\---



\## 2. Архитектура и стек технологий



\* \*\*Целевая платформа\*\*: Windows 10 (версия 1809 / сборка 17763 и выше), Windows 11.

\* \*\*Среда выполнения\*\*: .NET 8 (C# 12).

\* \*\*Интерфейс (GUI)\*\*: \*\*Windows App SDK / WinUI 3\*\*:

&#x20; \* Адаптивная верстка, поддержка светлой/тёмной тем (Fluent Design).

&#x20; \* Навигация: панель навигации `NavigationView` (Объекты, Журнал событий, Очередь команд, Настройки, Аналитика).

\* \*\*Фоновая служба (Worker Service)\*\*: 

&#x20; \* Системная служба Windows (`BackgroundService` / Windows Service).

&#x20; \* Обеспечивает независимый от интерфейса непрерывный приём, декодирование сообщений и сохранение данных.

\* \*\*База данных\*\*:

&#x20; \* \*\*SQLite\*\* в связке с \*\*Entity Framework Core 8\*\* и `Microsoft.Data.Sqlite`.

&#x20; \* \*\*Обязательные параметры отказоустойчивости\*\*:

&#x20;   \* Режим журнала: \*\*WAL (Write-Ahead Logging)\*\* — предотвращает блокировки при одновременном чтении интерфейсом и записи службой.

&#x20;   \* Таймаут блокировки: `Default Timeout = 5` секунд (предотвращает исключения `database is locked`).

&#x20;   \* Синхронизация: `PRAGMA synchronous = NORMAL`.

\* \*\*Аппаратный шлюз\*\*:

&#x20; \* Промышленный GSM/GPRS-модем, подключаемый по USB/RS-232 (виртуальный COM-порт).

&#x20; \* Движок работы с модемом: `Modem.Engine` (`System.IO.Ports`, работа с AT-командами в PDU и Text-режимах).

\## 3. Модули системы



\### 3.1. Ядро (Core)

\* Нормализация и типизация перечислений:

&#x20; \* `DeviceType`: `Ksital` (0), `RadsCCU` (1), `OvenPLC` (2).

\* Модель данных `MonitoredObject`:

&#x20; \* `Id` (GUID / строка), `Name`, `PhoneNumber` (уникальный ключ поиска), `DeviceType`, `District` (Район/Участок, обязательное поле), привязка зон контроля и датчиков.

\* `ImportExportService`:

&#x20; \* Экспорт структуры объектов в XLSX (`ClosedXML`).

&#x20; \* Импорт с поддержкой формата GSM Guard (CSV/XLSX).

&#x20; \* Алгоритм автоматической нормализации типов устройств:

&#x20;   \* `кситал\*`, `ksytal\*`, `ksital\*`, `кс\*` → \*\*КСИТАЛ\*\* (`0`)

&#x20;   \* `ццу\*`, `ccu\*`, `rads\*` → \*\*CCU-825\*\* (`1`)

&#x20;   \* `овен\*`, `oven\*`, `плк\*` → \*\*ОВЕН ПЛК\*\* (`2`)

&#x20; \* Механизм \*\*UPSERT\*\*: добавление новых объектов и бесконфликтное обновление существующих по совпадению номера телефона (`PhoneNumber`).



\### 3.2. Парсеры телеметрии (Parsers)

\* Распознавание входных сообщений от различных прошивок и протоколов:

&#x20; \* Разбор показаний термодатчиков (встроенные и проводные Dallas DS18B20).

&#x20; \* Контроль напряжения сети 220В (пропадание/восстановление питания).

&#x20; \* Состояние реле, входов охраны/шлейфов, баланс SIM-карты.

\* Формирование записей тревог (`AlarmEvent`) и телеметрии (`TelemetryRecord`).



\### 3.3. Модуль связи (Modem.Engine)

\* Постоянный мониторинг состояния COM-порта и уровня сигнала GSM.

\* Автовосстановление соединения при физическом переподключении USB/COM-кабеля.

\* Очередь исходящих команд (`OutgoingCommands`): отправка запросов состояния, управление реле через SMS.

\## 4. Требования к пользовательскому интерфейсу (WinUI 3)



\### 4.1. Главное окно (Диспетчерский пульт)

\* \*\*Левая панель (Навигация и фильтрация)\*\*:

&#x20; \* Дерево / сгруппированный список объектов по районам (`District`).

&#x20; \* Элемент объекта: наименование, телефон, индикатор типа устройства, статус связи (в сети / авария / нет данных).

&#x20; \* Быстрый поиск и фильтрация по названию, району и статусу.

\* \*\*Центральная/Правая рабочая зона\*\*:

&#x20; \* Вкладка \*\*Журнал событий и тревог\*\*: таблица с цветовой индикацией критичности (авария по температуре, пропадание 220В, взлом шлейфа), дата/время, объект, сообщение.

&#x20; \* Вкладка \*\*Очередь команд\*\*: список подготовленных, отправленных и подтвержденных SMS-команд.

&#x20; \* Вкладка \*\*Сводная телеметрия\*\*: текущее состояние выбранного объекта (состояние шлейфов, реле, актуальная температура датчиков).

\* \*\*Статусная строка (Нижняя панель)\*\*:

&#x20; \* Индикатор COM-порта (подключен / ошибка).

&#x20; \* Индикатор GSM-модема и уровень сигнала сети.

&#x20; \* Счетчик активных неквитированных аварий.



\### 4.2. Окно параметров и обслуживания (Settings)

\* Настройка COM-порта (выпадающий список с автообнаружением и кнопкой обновления списка).

\* \*\*Резервное копирование и восстановление\*\*:

&#x20; \* Создание полной горячей копии БД (`telemetry.db` + файлы WAL).

&#x20; \* Восстановление из резервной копии с автоматической безопасной остановкой службы сбора данных и перезапуском интерфейса.

\* \*\*Миграция и работа со списками\*\*:

&#x20; \* Кнопки импорта и экспорта Excel/CSV с отчетом о добавленных и обновленных записях.

\* \*\*Центр обновления (In-App Update)\*\*:

&#x20; \* Интеграция с GitHub Releases API.

&#x20; \* Проверка новых версий, индикатор загрузки дистрибутива, автономный накат обновления через фоновый скрипт с гарантированным сохранением рабочей базы данных.

\## 5. Надежность, развертывание и CI/CD



\* \*\*Автономность поставщика\*\*:

&#x20; \* Сборка в виде единого автономного пакета (`win-x64`, self-contained, .NET Runtime не требует отдельной установки).

\* \*\*Инсталлятор\*\*:

&#x20; \* \*\*Inno Setup\*\*:

&#x20;   \* Установка интерфейса и регистрация фоновой службы Windows.

&#x20;   \* Режим обновления: перезапись бинарных файлов без затирания `telemetry.db`.

\* \*\*CI/CD Автоматизация\*\*:

&#x20; \* Скрипты локального инкремента версий (`bump\_release.ps1`): автоматическое поднятие Patch/Minor-версий, сборка Release Notes.

&#x20; \* GitHub Actions: автоматическая компиляция установщика `Setup.exe` и публикация релиза при пуше тега версии (`vX.Y.Z`).

&#x20;  \* Проверка импорта списков объектов из GSM Guard.

&#x20;  \* Адаптация Inno Setup и сценария CI/CD под бинарные файлы WinUI 3.
